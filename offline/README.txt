HUNT ASSIST — OFFLINE LAPTOP BUILD

1. Keep this entire folder together.
2. Make sure Node.js 22 or newer is installed before you lose connectivity.
3. Double-click start.command.
4. Keep the Terminal window open while using the app.
5. Press Control-C in that Terminal window when finished.

The app opens at http://127.0.0.1:4317/#bear-targets.
